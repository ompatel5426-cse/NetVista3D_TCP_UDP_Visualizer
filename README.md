# NetVista 3D – TCP vs UDP Visualizer

An interactive network visualization project for **ITUC201: Fundamentals of Computer Networks**.

This project demonstrates the differences between connection-oriented and connectionless services using interactive packet animations and step-by-step explanations.

## Features

- TCP three-way handshake: SYN, SYN-ACK, ACK
- TCP data transfer and connection termination
- UDP datagram transmission without connection setup
- Animated packet movement
- Step-by-step simulation controls
- TCP vs UDP comparison table
- Networking concepts and exam-oriented learning

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Select TCP or UDP mode and interact with the simulation.

No additional installation is required for the basic browser-based visualization.

## Learning Objectives

- Understand connection-oriented and connectionless services.
- Learn the TCP three-way handshake.
- Understand UDP datagrams and their limitations.
- Compare TCP and UDP protocols.
